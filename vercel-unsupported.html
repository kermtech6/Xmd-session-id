Vercel ne peut pas héberger ce serveur de session

L’erreur FUNCTION_INVOCATION_FAILED / 500 est normale ici : Baileys garde une connexion WhatsApp WebSocket ouverte pendant plusieurs minutes. Vercel n’exécute que des fonctions serverless courtes, sans process persistant.

Déployez plutôt sur :

  • Render (Web Service, gratuit) — fichier render.yaml inclus
  • Railway
  • Koyeb
  • Ou en local : npm install && npm start → http://localhost:3999
