KERM - Session WhatsApp

Générez une session WhatsApp (indépendant du bot)

Scannez le QR code avec WhatsApp : Paramètres → Appareils connectés → Connecter un appareil. La session sera envoyée en PM.

Chargement du QR code...

Entrez votre numéro avec indicatif pays (ex: 237651234567). Le code sera envoyé sur votre appareil connecté, puis la session en PM.
